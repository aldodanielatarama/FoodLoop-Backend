PREGUNTAS FRECUENTES

Resolvemos tus dudas antes de empezar.

¿FoodLoop vende directamente los alimentos?

No. La propuesta conecta comercios con compradores y organizaciones. Cada publicación identifica al responsable del alimento y las condiciones del recojo.

¿Qué pasa si el alimento ya no puede entregarse a tiempo?

La plataforma debe impedir nuevas reservas cuando se supera la ventana segura. En esta demo se comprueban las fechas configuradas por cada lote.

¿Cómo evitan que dos organizaciones reciban las mismas unidades?

La asignación requiere comprobar la disponibilidad antes de confirmar. La versión demo controla el stock dentro de una sesión; en producción se necesita una transacción de base de datos.

¿Puedo comprar y también donar?

Un establecimiento puede publicar lotes de venta y de donación de forma diferenciada. Las reservas y las asignaciones se gestionan por lote.

OPERACIÓN FOODLOOP

Desde un excedente hasta una entrega verificada.

Una experiencia clara para comprar, donar y recoger alimentos con menos incertidumbre.

01 · PUBLICAR

Registrar lote y condiciones

El comercio informa stock, preparación, límite de recojo, alérgenos, conservación y precio o modalidad de donación.

02 · ENCONTRAR

Descubrir lo compatible

Los usuarios filtran por distrito, producto, horario y modalidad. Se advierte si la ventana de entrega ya terminó.

03 · ASIGNAR

Evitar reservas duplicadas

Las compras consumen disponibilidad al confirmar; las donaciones esperan la decisión del comercio y permiten asignación parcial.

04 · COORDINAR

Preparar y recoger

Se muestran estado, hora límite y código de validación. Un cálculo de ruta real requiere una API externa.

05 · VERIFICAR

Confirmar la recepción

El comercio registra la entrega para que cuente como operación completada y quede historial.

06 · APRENDER

Analizar resultados

El panel muestra unidades recuperadas, operaciones, ingresos demostrativos y una proyección heurística ilustrativa.

🧠

¿Y la inteligencia artificial?

La versión demostrativa incluye una recomendación simple basada en stock y actividad. El módulo de predicción con IA real necesitará historial, modelo, métricas de evaluación e integración específica.

IMPACTO Y TRAZABILIDAD

Lo importante no es publicar. Es recuperar.

Este panel calcula indicadores a partir de las operaciones marcadas como entregadas en el navegador de prueba.

¿Cómo calculamos los indicadores?

Los kilogramos se calculan sumando las unidades entregadas por el peso informado de cada lote. El ahorro y la recuperación son referencias de demostración, no resultados reales de FoodLoop.

Publicado ≠ recuperadoSolo las entregas confirmadas forman parte del indicador de alimentos recuperados.CO₂ evitado: no estimadoNecesitaríamos una metodología ambiental verificable y datos adicionales para mostrar esta cifra con rigor.
